Конструктор товарных квизов для WordPress и WooCommerce.

== Установка ==
1. Загрузите ZIP через «Плагины → Добавить плагин → Загрузить плагин».
2. Активируйте Purple Web Quiz Builder.
3. В меню WordPress откройте «Квизы».
4. Создайте квиз, заполните заголовок и описание, опубликуйте.
5. Используйте шорткод вида [pw_quiz id="123"].

== Текущая версия ==
Этап 1: каркас плагина, список квизов, создание/редактирование, описание, дублирование и шорткод.
Конструктор вопросов, изображения, ветвление и подбор товаров будут добавлены в следующих версиях.
